# 网课小助手：DeepSeek 答题与视频倍速

基于用户提供的 MIT 脚本整理，保留原作者 `isMobile` 和命名空间 `noshuang`。当前版本 **0.3.17**。

[安装脚本](https://raw.githubusercontent.com/WuDiAN233/chaoxing-deepseek-helper/main/chaoxing-deepseek-helper.user.js) · [下载发布包](https://github.com/WuDiAN233/chaoxing-deepseek-helper/releases/latest) · [验证说明](VERIFICATION.md)

## 功能

- **1–10 倍滑条，步长 0.5**：保留所选速度，显示实际速度；学习通按课程设置和播放器原生菜单确定可用上限。
- **倍速识别修复**：允许倍速且原生支持 4× 等更高速度时，不再统一限为 2×。课程禁用倍速或权限无法识别时采用 1×；菜单无法识别且课程明确允许时使用 2×。
- **持续续播**：暂停后自动恢复，不按暂停或失败次数停用。临时播放失败会逐步拉开尝试间隔，最长 3 秒；资源加载错误时保留监听，原生播放器就绪后继续。学习通续播不再受脚本自身的窗口焦点限制；弹题期间等待作答，视频结束、任务完成或切章后停止旧视频的恢复。
- **DeepSeek 三路投票**：默认 `deepseek-flash`，关闭深度思考。前两路一致时跳过第三路，同题结果缓存 24 小时、最多 100 条。
- **答题辅助与任务推进**：支持视频弹题、章节测验的结构化填写及填写确认，可按设置开启自动提交和下一章。
- **任务完成确认**：检查平台任务标记，必要时回读同一官方课程页；播放结束不会直接当作平台已完成。

## 安装与使用

1. 在 Chrome 或 Edge 安装 [Tampermonkey](https://www.tampermonkey.net/)。
2. 点击上方“安装脚本”，在脚本管理器中确认安装。也可以解压发布包，导入 `chaoxing-deepseek-helper.user.js`。
3. 打开学习通课程页面。在“设置”调整倍速，在“答题”填写**自己的** DeepSeek API Key 并测试连接。
4. 需要自动处理时，在“设置”开启章节作业自动提交、自动下一章节及视频弹题自动处理，并关闭“只答题，不做其他”，然后刷新课程页面。

新安装保留手动控制：自动提交和自动切章默认关闭。更新会迁移已有设置。旧脚本与本脚本同时启用时可能互相影响，请在脚本管理器中停用旧版本。

### 为什么选择 10×，实际还是 1× 或 2×？

滑条保存的是你的选择；实际速度还取决于课程是否允许倍速、播放器原生菜单以及临时回读结果。禁止倍速的课程仍采用 1×。本版本修复可用倍速的识别，不修改后台观看时长或完成字段。

任务点需要平台确认。请遵循课程页面显示的有效观看条件，出现额外验证时按页面提示处理。

### 答案与费用

三路来自同一模型的不同提示，并不是三个独立题库。多数票和“无多数时选择可用答案”都可能出错；成功填写比例不代表正确率。请核对答案。API 调用按你自己的 DeepSeek 账户计费。

## Key 与数据

仓库和发布包不包含个人 API Key、Cookie、浏览器配置或学习记录。Key 由用户在面板填写并保存在脚本管理器中，调用官方 DeepSeek API 时使用；源码、网页配置和日志不保存 Key。AI 请求仅允许 `api.deepseek.com`，不接入付费卡密题库。

## 开发与验证

需要 Node.js 22 或更新版本，以及本机 Chrome 或 Edge。没有额外 npm 依赖。

```sh
npm run check
npm test
npm run build
```

浏览器路径不能自动找到时，用 `CHROME_BIN` 指定浏览器可执行文件。首次测试会下载固定版本的前端依赖并核对 SHA-256；缓存、模拟页面及验证报告保存在被 Git 忽略的 `.fixtures/`，打包输出在 `.artifacts/`。

测试使用真实浏览器、DOM 和媒体元素；全部 AI 响应由本地模拟提供，不读取个人 Key，也不调用 DeepSeek。当前本地 91 项通过；Edge 中已更新现有脚本，在真实学习通视频上连续触发 12 次暂停，均自动恢复且进度前进。完整播放、答题与切章闭环的验证范围见 [VERIFICATION.md](VERIFICATION.md)。
